# Plantillas de documentación

Documentación en español, en markdown, en el directorio `docs/` del proyecto.

- `readme.md.tmpl` → `readme.md` (raíz).
- `technical-debt.md.tmpl` → `docs/technical-debt.md`.
- `adr.md.tmpl` → `docs/adr/NNNN-titulo-corto.md` (numeración correlativa).
- `architecture.md.tmpl` → `docs/architecture.md` (diagrama mermaid); además `class-diagrams.md`, `use-cases.md`, `installation.md` y `configuration.md`.
- `gitignore.md`: fragmentos de `.gitignore` por tecnología.

# Plantillas

Plantillas que el agente instancia durante el onboarding o al generar artefactos. Los marcadores `__NOMBRE__` se sustituyen por los datos del producto.

- [github/](github/README.md): dependabot, workflows y rulesets.
- [openspec/](openspec/README.md): configuración de OpenSpec.
- [docs/](docs/README.md): documentación del proyecto y `.gitignore`.
- [sql/](sql/README.md): script de base de datos.
